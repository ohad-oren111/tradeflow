# S18 — Russell reconstitution — UNTESTABLE-HERE

**Verdict: UNTESTABLE-HERE (n gate). Not run.**

Structural sample-size failure, known before any data work: the reconstitution happens
once per year (June), so even with the full FTSE/Russell era a portfolio-level episode
count tops out around n≈40 — far below the pre-registered n≥200 gate, with no honest way
to inflate it (treating each added/deleted STOCK as an independent trade is the n-inflation
trap: they are one cross-sectionally correlated event per year). Running it anyway would
produce a number that cannot clear the bar by construction; per the work order, it is
documented and not run.

**Unlock:** none at this bar. The hypothesis is structurally untestable at n≥200 on annual
events; it would need either a relaxed (pre-registered, justified) gate for slow event
strategies or pooling with other index-rebalance events — a different hypothesis.
